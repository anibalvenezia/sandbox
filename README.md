# Lienzo cuadriculado

Cuadrícula de celdas de **1 cm × 1 cm** para pintar y dividir.

## Uso

- **Pintar**: selecciona un color y toca o arrastra sobre las celdas.
- **Partir vertical / horizontal**: elige el modo y toca una celda.
- **Borrar**: quita el color de las celdas.

Atajos de teclado (escritorio): `P` pintar · `V` vertical · `H` horizontal · `E` borrar.

## Despliegue en Vercel

1. Entra a [vercel.com/new](https://vercel.com/new).
2. Importa el repositorio `anibalvenezia/sandbox`.
3. Deja **Framework Preset** en *Other* (sitio estático, sin build).
4. Pulsa **Deploy**.

La app quedará en una URL pública tipo `https://sandbox-….vercel.app`.
